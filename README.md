## Назначение скриптов

В папке `scripts` находятся два основных файла исследовательского конвейера:

### `social_comments_solid.py`

Собирает комментарии из **YouTube, VK и Telegram** по заданным поисковым запросам.

Скрипт:

- ищет публикации и комментарии по теме предпринимательства;
- приводит данные разных площадок к единому формату;
- удаляет дубликаты;
- сохраняет новые записи в CSV сразу во время сбора;
- позволяет продолжить работу после остановки без повторной записи уже собранных комментариев.

### `llm_analyze_solid.py`

Анализирует собранные комментарии и извлекает из них конкретные проблемы предпринимателей — **pain units**.

Скрипт:

- очищает и фильтрует тексты;
- разбивает длинные комментарии на смысловые фрагменты;
- определяет наличие бизнес-контекста и сигнала проблемы;
- сочетает регулярные правила и SBERT-эмбеддинги;
- относит фрагменты к категориям болей;
- формирует CSV-, Excel- и Markdown-отчёты с примерами, частотами и сводной статистикой.

## Как эти файлы использовались в решении

Скрипты позволили перейти от отдельных мнений к воспроизводимому анализу большого массива пользовательских высказываний. В очищенный корпус исследования вошло **2 458 комментариев** о запуске бизнеса, поиске первых клиентов, окупаемости, банках, налогах, эквайринге и маркетплейсах.

Полученные результаты помогли:

1. Выделить повторяющиеся финансовые, операционные и организационные проблемы.
2. Оценить частоту разных болей, а не опираться только на отдельные интервью.
3. Сохранить доказательные цитаты для каждой категории.
4. Сопоставить выводы из социальных сетей с опросом, интервью и анализом банковских продуктов.
5. Подтвердить главный вывод исследования: начинающему предпринимателю не столько не хватает отдельных сервисов, сколько понятного маршрута от идеи до первой выручки.

Именно этот анализ стал одним из оснований для концепции **AlfaGen:Start**: Mentor строит персональную карту развития, Copilot помогает выполнять текущие задачи, а Community даёт доступ к партнёрам, единомышленникам и первым клиентам.

## Быстрый запуск

Требуется **Python 3.10 или новее**.

### 1. Установка

```bash
python -m venv .venv
```

Активация окружения:

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

Установка проекта и зависимостей:

```bash
pip install -e .
```

### 2. Настройка ключей

Создайте файл `.env` в корне проекта:

```env
YOUTUBE_API_KEY=your_youtube_api_key
VK_ACCESS_TOKEN=your_vk_access_token
VK_API_VERSION=5.199

TELEGRAM_API_ID=your_telegram_api_id
TELEGRAM_API_HASH=your_telegram_api_hash
TELEGRAM_PHONE=your_phone
```

Указывать нужно только ключи тех платформ, которые используются при сборе.

### 3. Сбор комментариев

```bash
collect-comments \
  --queries "молодой бизнес,как открыть ИП,первые клиенты" \
  --youtube \
  --vk-groups "group_name" \
  --tg-channels "@channel_name" \
  --out data/social_comments.csv
```

Можно использовать только одну или несколько платформ.

### 4. Анализ болей

```bash
analyze-pains data/social_comments.csv \
  --output-dir results
```

Основные результаты появятся в папке `results`:

- `pain_summary.csv` — сводка по категориям болей;
- `pain_units.csv` — найденные смысловые фрагменты и классификация;
- `comments_with_extracted_pains.csv` — исходные комментарии с результатами анализа;
- `pain_analysis_audit.xlsx` — файл для ручной проверки;
- `report_v3.md` — итоговый текстовый отчёт.
